Pengaturan Undangan
Domain utama undangan Anda. Contoh: https://uid007.github.io/invitation. URL undangan tamu akan ditambahkan parameter ?to=Nama+Tamu di belakang URL ini.
Gunakan {{link_undangan}} sebagai placeholder lokasi link undangan.
  • Gunakan *teks* untuk membuat teks menjadi tebal.
  • Gunakan _teks_ untuk membuat teks menjadi miring.
  • Gunakan ~teks~ untuk membuat teks tercoret.
Tambah Penerima Undangan
Awali dengan kode negara tanpa tanda '+', contoh: 628123456789. Jika diisi, tombol send akan langsung membuka chat ke nomor tersebut.
